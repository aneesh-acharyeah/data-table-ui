# Data Table UI (JavaScript)

A clean and responsive data table built with vanilla JavaScript — no libraries required.  
Supports sorting, pagination, global search, column visibility toggle, and CSV export.

## Features
- Sort any column (ascending / descending)
- Global search with highlighted matches
- Pagination with adjustable page size
- Show/Hide columns dynamically
- Export the current view to CSV
- Dark modern UI

## Tech Used
- HTML
- CSS
- JavaScript (No frameworks)

## How to Run
Just open `index.html` in your browser.
